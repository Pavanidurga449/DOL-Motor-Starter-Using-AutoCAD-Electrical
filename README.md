# DOL Motor Starter Using AutoCAD Electrical

## Project Overview

This project presents the electrical design of a Direct-On-Line (DOL) motor starter using AutoCAD Electrical.

The design includes both the power circuit and control circuit for starting, stopping, and protecting a three-phase induction motor.

## Objectives

- To design a DOL motor starter using AutoCAD Electrical.
- To understand the power circuit and control circuit of a motor starter.
- To implement start and stop control of a three-phase induction motor.
- To incorporate overload protection.
- To create a professional electrical schematic.

## Software Used

- AutoCAD Electrical

## Main Components

- Three-phase R-Y-B supply
- Circuit protection device
- Contactor
- Overload relay
- Start push button
- Stop push button
- Auxiliary contact
- Three-phase induction motor

## Power Circuit

The power circuit supplies three-phase electrical power to the induction motor through the protection device, contactor, and overload relay.

## Control Circuit

The control circuit is used to control the contactor coil. The Start push button energizes the contactor, while the Stop push button de-energizes it. An auxiliary contact is used for holding/sealing the contactor after the Start push button is released.

The overload relay provides protection by opening the control circuit when an overload condition occurs.

## Working Principle

When the Start push button is pressed, the contactor coil is energized and its main contacts close. The three-phase supply is then connected to the motor.

The auxiliary contact maintains the contactor coil energized after the Start button is released.

When the Stop push button is pressed, or when the overload relay operates, the contactor coil is de-energized and the motor is disconnected from the supply.
